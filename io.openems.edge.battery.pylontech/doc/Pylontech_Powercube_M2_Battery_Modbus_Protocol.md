# Pylontech Powercube M2 电池管理系统 Modbus 通信协议 V1.0

**版本**: V1.0 (基于代码逆向工程) | 2025-11-30
**作者**: OpenEMS Pylontech Powercube M2 电池模块开发团队

---

## 1. 简介

1. 本文档描述了 Pylontech Powercube M2 电池管理系统与 OpenEMS 系统之间的 Modbus 通信协议；
2. 本协议基于标准 Modbus RTU 协议，定义了所有可访问的寄存器地址及其具体含义；
3. 本文档基于 OpenEMS 源码 `io.openems.edge.battery.pylontech.powercubem2` 模块逆向工程分析得出；
4. 物理层：RS485/Modbus-RTU；
5. 默认通信波特率：未在代码中明确指定，需根据 Pylontech 官方文档配置；
6. 通信端口配置：8 个数据位，1 个停止位，无奇偶校验位；
7. Pylontech BMS 作为从设备，OpenEMS 作为主设备；
8. Pylontech 在此协议中的默认 Modbus 设备地址：0x01；
9. 支持最多 32 个电池堆（每个堆包含多个模块和电池单元）；
10. 支持动态电池堆配置，通过回调函数自动初始化每个堆的通道。

## 2. 报文格式

### 标准 Modbus RTU 报文格式：

| 字段 | 长度 | 描述 |
|------|--------|------|
| 设备地址 | 1字节 | 通信网络中设备的地址，范围 1-247 |
| 功能码 | 1字节 | 描述本次操作的方法 |
| 数据 | N字节 | 寄存器地址和数据 |
| CRC | 2字节 | Modbus CRC-16 校验 |

### 设备地址：
- Pylontech BMS 的默认设备地址：**0x01**
- 如果网络中存在多个设备，每个设备必须有唯一的设备地址

### 功能码：

| 功能码 | 方法 | 描述 |
|--------|------|------|
| 03H    | 读保持寄存器 | 从寄存器读取值 |
| 06H    | 写单个寄存器 | 向特定寄存器写入单个值 |
| 10H    | 写多个寄存器 | 向相应寄存器写入多个值 |

### CRC：
- 多项式 CRC-16/Modbus (x16 + x15 + x2 + 1)

## 3. 寄存器读写方法

### 读保持寄存器 (03H)

**请求格式：**
| 字段 | 长度 | 描述/范围 |
|------|--------|-----------|
| 设备地址 | 1字节 | 0x01 (默认) |
| 功能码 | 1字节 | 0x03 |
| 起始地址高字节 | 1字节 | 0x0000 至 0xFFFF |
| 起始地址低字节 | 1字节 | |
| 寄存器数量高字节 | 1字节 | 1 至 127 |
| 寄存器数量低字节 | 1字节 | 2字节每寄存器 |
| CRC | 2字节 | 低字节在前 |

**正常响应格式：**
| 字段 | 长度 | 描述/范围 |
|------|--------|-----------|
| 设备地址 | 1字节 | 0x01 (默认) |
| 功能码 | 1字节 | 0x03 |
| 字节计数 | 1字节 | 2 至 254 |
| 寄存器值 | 2*n字节 | n = 寄存器数量 |
| CRC | 2字节 | 低字节在前 |

**异常响应格式：**
| 字段 | 长度 | 描述/范围 |
|------|--------|-----------|
| 设备地址 | 1字节 | 0x01 (默认) |
| 功能码 + 0x80 | 1字节 | 0x83 |
| 异常码 | 1字节 | 详见第 13 节 |
| CRC | 2字节 | 低字节在前 |

### 写单个寄存器 (06H)

**请求格式：**
| 字段 | 长度 | 描述/范围 |
|------|--------|-----------|
| 设备地址 | 1字节 | 0x01 (默认) |
| 功能码 | 1字节 | 0x06 |
| 起始地址高字节 | 1字节 | 0x0000 至 0xFFFF |
| 起始地址低字节 | 1字节 | |
| 寄存器值高字节 | 1字节 | |
| 寄存器值低字节 | 1字节 | |
| CRC | 2字节 | 低字节在前 |

## 4. 寄存器地址映射

### 寄存器地址计算规则
寄存器地址 = 基地址 + 偏移地址

### 系统级基地址
| 功能区域 | 基地址 | 描述 |
|----------|--------|------|
| 设备信息 | 0x1000 | 设备版本和系统配置信息 |
| 远程控制 | 0x1090 | 睡眠/唤醒控制寄存器 |
| 系统信息 | 0x1100 | 系统状态、电压、电流等核心信息 |
| 电池堆区域 | 0x0D00 + 堆号 × 0x0700 | 每个电池堆的独立信息区域 |

## 5. 设备信息寄存器 (基地址: 0x1000)

### 5.1 设备版本信息 (偏移 0x000A)

| 偏移地址 | 寄存器地址 | 名称 | 读写 | 数据类型 | 描述与单位 |
|------------|------------|------|------|----------|----------------------|
| 0x000A | 0x100A | VERSION_RAW | 只读 | Unsigned | 原始版本号寄存器，用于生成版本字符串 |
| 0x000B | 0x100B | PYLONTECH_INTERNAL_VERSION_NUMBER | 只读 | Unsigned | Pylontech 内部版本号 |
| 0x000C | 0x100C | SYSTEM_NUMBER_OF_PARALLEL_PILES | 只读 | Unsigned | 系统中并行电池堆数量，范围：1 ~ 32 |

### 5.2 版本号转换规则
原始版本号 (0x100A) 按以下格式转换为版本字符串：
- Bit 0-3: 次版本号第一位 (16进制)
- Bit 4-7: 次版本号第二位 (16进制)
- Bit 8-11: 主版本号第一位 (16进制)
- Bit 12-15: 主版本号第二位 (16进制)
- 格式：V主版本号.次版本号

## 9. 电池堆信息寄存器 (动态基地址)

### 9.1 电池堆基地址计算
每个电池堆的基地址 = 0x0D00 + 堆号 × 0x0700
- 电池堆 1: 0x0D00 + 1 × 0x0700 = 0x1400
- 电池堆 2: 0x0D00 + 2 × 0x0700 = 0x1B00
- ...
- 电池堆 N: 0x0D00 + N × 0x0700

## 11. 通信参数与安全

### 11.1 通信参数
- **波特率**: 根据 Pylontech 官方文档配置
- **数据位**: 8 位
- **停止位**: 1 位
- **校验位**: 无校验
- **设备地址**: 默认 0x01

### 11.2 CRC 校验
- 使用标准 Modbus CRC-16 算法
- 多项式 CRC-16/Modbus (x16 + x15 + x2 + 1)
- 低字节在前，高字节在后

### 11.3 动态配置支持
- 系统支持最多 32 个并行电池堆
- 通过 `NUMBER_OF_PILES_IN_PARALLEL` 寄存器自动检测
- OpenEMS 动态创建每个电池堆的通信通道
- 每个电池堆占用 0x0700 地址空间

Pylontech Powercube M2 电池模块包含完整的状态机实现：

## 15. 附录

### 15.1 数据类型说明
- **Unsigned**: 无符号整数
- **Signed**: 有符号整数
- **Enum**: 枚举类型
- **Boolean**: 布尔类型 (0/1)
- **Bits**: 位域类型

### 15.2 单位换算
- **电压**:
  - 系统/电池堆电压: 1V = 10 (寄存器值)
  - 电池单元电压: 1V = 1000 (寄存器值)
  - 模块电压: 1V = 100 (寄存器值)
- **电流**: 1A = 100 (寄存器值) (有符号，正值为充电，负值为放电)
- **温度**: 1°C = 10 (寄存器值) (有符号)
- **SOC/SOH**: 1% = 1 (寄存器值)
- **容量**: 1Wh = 1 (寄存器值)
- **绝缘电阻**: 1kΩ = 1 (寄存器值)

### 15.3 位域说明
- 状态寄存器采用位域定义，Bit0 为最低位
- 位值含义请参考具体寄存器描述
- 0 表示正常状态，1 表示告警/保护/错误状态

### 15.4 地址范围总结
- **设备信息**: 0x1000-0x10FF
- **远程控制**: 0x1090-0x109F
- **系统信息**: 0x1100-0x11FF
- **电池堆 1**: 0x1400-0x16FF
- **电池堆 2**: 0x1B00-0x1DFF
- **电池堆 N**: 0x0D00 + N×0x0700 至 0x0D00 + N×0x0700 + 0x02FF

### 15.5 OpenEMS 通道命名规则
- 系统级通道: 直接使用寄存器名称
- 电池堆通道: `PILE_{堆号}_{寄存器名称}` 格式
- 状态机通道: `STATE_MACHINE`, `RUN_FAILED`
- 控制通道: `SLEEP_WAKE_CHANNEL`
