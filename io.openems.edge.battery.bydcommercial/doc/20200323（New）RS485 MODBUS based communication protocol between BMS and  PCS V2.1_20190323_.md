## 1. 简介

1. 本文档用于储能系统中电池管理系统（BMS）与PCS之间的通信；
2. 本协议基于标准Modbus通信协议，定义了寄存器地址及其具体含义；
3. 关于读写一个或多个寄存器值的方法和顺序，可参考标准Modbus协议；
4. 物理层：RS485/MODBUS-RTU；
5. 默认通信波特率：57600 bit/s；
6. 通信端口配置：8个数据位，1个停止位，无奇偶校验位；
7. BMS作为从设备，PCS作为主设备；
8. BMS在此协议中有一个默认地址：0x01。如果地址分配冲突，请联系我们；
9. 两次不同读写操作之间的间隔时间不能小于300ms；

---

## 2. 报文格式

Modbus协议报文格式：

| 设备地址 | 功能码 | 数据  | CRC   |
| -------- | ------ | ----- | ----- |
| 1字节    | 1字节  | N字节 | 2字节 |

- **设备地址**：通信网络中设备不能共享同一地址。每个设备必须有唯一的设备地址，取值范围0-255。
- **功能码**：描述每次操作的方法。

| 功能码 | 方法         | 描述                 |
| ------ | ------------ | -------------------- |
| 03H    | 读寄存器     | 从寄存器读取值       |
| 06H    | 写单个寄存器 | 向特定寄存器写单个值 |
| 10H    | 写多个寄存器 | 向相应寄存器写多个值 |

- **CRC**：多项式 CRC-16/MODBUS x16+x15+x2+1。

## 3. 寄存器读写方法

### 读寄存器 (03H)

**请求：**

| 字段             | 大小 | 值/范围          |
| ---------------- | ---- | ---------------- |
| 地址             | 1B   | 0x01 (默认)      |
| 功能码           | 1B   | 0x03             |
| 起始地址高字节   | 1B   | 0x0000 至 0xFFFF |
| 起始地址低字节   | 1B   |                  |
| 寄存器数量高字节 | 1B   | 1 至 127         |
| 寄存器数量低字节 | 1B   | 2字节每寄存器    |
| CRC              | 2B   | 低字节在前       |

**正常响应：**

| 字段     | 大小 | 值/范围        |
| -------- | ---- | -------------- |
| 地址     | 1B   | 0x01 (默认)    |
| 功能码   | 1B   | 0x03           |
| 字节计数 | 1B   | 2 至 254       |
| 寄存器值 | 2*nB | n = 寄存器数量 |
| CRC      | 2B   | 低字节在前     |

**异常响应：**

| 字段     | 大小 | 值/范围     |
| -------- | ---- | ----------- |
| 地址     | 1B   | 0x01 (默认) |
| 错误码   | 1B   | 0x83        |
| 异常类型 | 1B   | 详见表3.0   |
| CRC      | 2B   | 低字节在前  |

### 写单个寄存器 (06H)

**请求：**

| 字段           | 大小 | 值/范围          |
| -------------- | ---- | ---------------- |
| 地址           | 1B   | 0x01 (默认)      |
| 功能码         | 1B   | 0x06             |
| 起始地址高字节 | 1B   | 0x0000 至 0xFFFF |
| 起始地址低字节 | 1B   |                  |
| 寄存器值高字节 | 1B   |                  |
| 寄存器值低字节 | 1B   |                  |
| CRC            | 2B   | 低字节在前       |

**正常响应：** (与请求格式相同)

**异常响应：**

| 字段     | 大小 | 值/范围     |
| -------- | ---- | ----------- |
| 地址     | 1B   | 0x01 (默认) |
| 错误码   | 1B   | 0x86        |
| 异常类型 | 1B   | 详见表3.0   |
| CRC      | 2B   | 低字节在前  |

### 写多个寄存器 (10H)

**请求：**

| 字段             | 大小 | 值/范围          |
| ---------------- | ---- | ---------------- |
| 地址             | 1B   | 0x01 (默认)      |
| 功能码           | 1B   | 0x10             |
| 起始地址高字节   | 1B   | 0x0000 至 0xFFFF |
| 起始地址低字节   | 1B   |                  |
| 寄存器数量高字节 | 1B   | 1 至 127         |
| 寄存器数量低字节 | 1B   | 2字节每寄存器    |
| 字节计数         | 1B   | 2 至 254         |
| 寄存器值         | 2*nB | n = 寄存器数量   |
| CRC              | 2B   | 低字节在前       |

**正常响应：**

| 字段             | 大小 | 值/范围          |
| ---------------- | ---- | ---------------- |
| 地址             | 1B   | 0x01 (默认)      |
| 功能码           | 1B   | 0x10             |
| 起始地址高字节   | 1B   | 0x0000 至 0xFFFF |
| 起始地址低字节   | 1B   |                  |
| 寄存器数量高字节 | 1B   | 0 至 127         |
| 寄存器数量低字节 | 1B   | 2字节每寄存器    |
| CRC              | 2B   | 低字节在前       |

**异常响应：**

| 字段     | 大小 | 值/范围     |
| -------- | ---- | ----------- |
| 地址     | 1B   | 0x01 (默认) |
| 错误码   | 1B   | 0x90        |
| 异常类型 | 1B   | 详见表3.0   |
| CRC      | 2B   | 低字节在前  |

## 4. 寄存器定义

### 寄存器地址 = 基地址 + 偏移地址

每个电池簇的基地址如下：

| 簇号 | 基地址 |
| ---- | ------ |
| 簇 1 | 0x2000 |

如果存在多个簇，可以通过更改基地址来访问任何簇的信息。以下文档仅列出一个簇的信息。

---

### BMS控制寄存器

| 偏移地址 | 名称             | 读写 | 描述             |
| -------- | ---------------- | ---- | ---------------- |
| 0x0010   | 主回路接触器控制 | 读写 | 0x1: 开, 0x0: 关 |
