**地址**: 深圳市龙岗区宝龙三路33号

**作者**: OpenEMS BYD 电池模块开发团队

## 1. 简介

1. 本文档描述了 BYD (比亚迪) C130 商用电池管理系统与 OpenEMS 系统之间的 Modbus 通信协议；
2. 本协议基于标准 Modbus RTU 协议，定义了所有可访问的寄存器地址及其具体含义；
3. 本文档基于 OpenEMS 源码 `io.openems.edge.battery.bydcommercial` 模块逆向工程分析得出；
4. 物理层：RS485/Modbus-RTU；
5. 默认通信波特率：57600 bit/s；
6. 通信端口配置：8 个数据位，1 个停止位，无奇偶校验位；
7. BYD BMS 作为从设备，OpenEMS 作为主设备；
8. BYD 在此协议中的默认 Modbus 设备地址：0x01；
9. 两次不同读写操作之间的间隔时间不能小于 300ms；
10. 支持最多 20 个电池模块（240 个单体电池，48 个温度传感器）；

## 2. 报文格式

### 标准 Modbus RTU 报文格式：

| 字段 | 长度 | 描述 |
|------|--------|------|
| 设备地址 | 1字节 | 通信网络中设备的地址，范围 1-247 |
| 功能码 | 1字节 | 描述本次操作的方法 |
| 数据 | N字节 | 寄存器地址和数据 |
| CRC | 2字节 | Modbus CRC-16 校验 |

### 设备地址：
- BYD BMS 的默认设备地址：**0x01**
- 如果网络中存在多个设备，每个设备必须有唯一的设备地址

### 功能码：

| 功能码 | 方法 | 描述 |
|--------|------|------|
| 03H    | 读保持寄存器 | 从寄存器读取值 |
| 06H    | 写单个寄存器 | 向特定寄存器写入单个值 |
| 10H    | 写多个寄存器 | 向相应寄存器写入多个值 |

### CRC：
- 多项式 CRC-16/Modbus (x16 + x15 + x2 + 1)

## 3. 寄存器读写方法

### 读保持寄存器 (03H)

**请求格式：**
| 字段 | 长度 | 描述/范围 |
|------|--------|-----------|
| 设备地址 | 1字节 | 0x01 (默认) |
| 功能码 | 1字节 | 0x03 |
| 起始地址高字节 | 1字节 | 0x0000 至 0xFFFF |
| 起始地址低字节 | 1字节 | |
| 寄存器数量高字节 | 1字节 | 1 至 127 |
| 寄存器数量低字节 | 1字节 | 2字节每寄存器 |
| CRC | 2字节 | 低字节在前 |

**正常响应格式：**
| 字段 | 长度 | 描述/范围 |
|------|--------|-----------|
| 设备地址 | 1字节 | 0x01 (默认) |
| 功能码 | 1字节 | 0x03 |
| 字节计数 | 1字节 | 2 至 254 |
| 寄存器值 | 2*n字节 | n = 寄存器数量 |
| CRC | 2字节 | 低字节在前 |

**异常响应格式：**
| 字段 | 长度 | 描述/范围 |
|------|--------|-----------|
| 设备地址 | 1字节 | 0x01 (默认) |
| 功能码 + 0x80 | 1字节 | 0x83 |
| 异常码 | 1字节 | 详见第 7 节 |
| CRC | 2字节 | 低字节在前 |

### 写单个寄存器 (06H)

**请求格式：**
| 字段 | 长度 | 描述/范围 |
|------|--------|-----------|
| 设备地址 | 1字节 | 0x01 (默认) |
| 功能码 | 1字节 | 0x06 |
| 起始地址高字节 | 1字节 | 0x0000 至 0xFFFF |
| 起始地址低字节 | 1字节 | |
| 寄存器值高字节 | 1字节 | |
| 寄存器值低字节 | 1字节 | |
| CRC | 2字节 | 低字节在前 |

## 14. 通信安全与可靠性

### 14.1 通信参数
- **波特率**: 57600 bps
- **数据位**: 8 位
- **停止位**: 1 位
- **校验位**: 无校验
- **通信超时**: 默认 300ms 最小间隔

### 14.2 重试机制
- **最大重试次数**: 30 次 (定义在 `Constants.RETRY_COMMAND_MAX_ATTEMPTS`)
- **重试间隔**: 30 秒 (定义在 `Constants.RETRY_COMMAND_SECONDS`)

### 14.3 CRC 校验
- 使用标准 Modbus CRC-16 算法
- 多项式 CRC-16/Modbus (x16 + x15 + x2 + 1)
- 低字节在前，高字节在后

## 16. 使用建议

### 16.1 系统集成
1. 确保设备地址配置正确，避免地址冲突；
2. 定期检查通信状态和报警信息；
3. 实现适当的错误处理和重试机制；
4. 监控系统绝缘电阻值，确保安全运行。

### 16.2 维护建议
1. 定期检查单体电池电压差值，及时发现电池不均衡；
2. 监控温度传感器数据，确保电池工作在安全温度范围；
3. 关注通信状态，及时发现从模块通信故障；
4. 定期备份系统配置和运行数据。

### 16.3 故障诊断
- 通过查看各级报警寄存器，快速定位系统故障类型；
- 使用通信故障寄存器诊断模块间通信问题；
- 通过温度和电压异常诊断电池健康状态。

## 17. 附录

### 17.1 数据类型说明
- **Unsigned**: 无符号整数
- **Signed**: 有符号整数
- **Enum**: 枚举类型
- **Bits**: 位域类型

### 17.2 单位换算
- **电压**: 1mV = 0.001V
- **电流**: 0.1A = 0.1A (Signed)
- **功率**: 通过电压×电流计算
- **温度**: 0.1°C = 0.1°C (Signed)
- **SOC/SOH**: 1% = 1%
- **绝缘电阻**: 1kΩ/bit

### 17.3 位域说明
- 报警寄存器采用位域定义，Bit0 为最低位
- 位值含义请参考具体寄存器描述
- 0 表示正常状态，1 表示报警状态

### 17.4 地址范围
- **控制寄存器**: 0x2000-0x201F
- **状态寄存器**: 0x2100-0x21FF
- **报警寄存器**: 0x2140-0x218F
- **配置寄存器**: 0x2190-0x21FF
- **电压寄存器**: 0x2800-0x28FF
- **温度寄存器**: 0x2C00-0x2CFF
